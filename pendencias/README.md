# Pendências

Fila de alterações no vault do Obsidian que precisam ser feitas **no computador**,
porque foram identificadas a partir do tablet e o conector de Google Drive usado
lá só sabe **criar** arquivos — não sabe editar, renomear nem apagar.

## Como funciona

- Um arquivo por data: `AAAA-MM-DD-vault.md`.
- Cada item é uma caixa `- [ ]`, com o caminho exato no vault e o texto exato a
  aplicar. Quem executa não deve precisar reconstruir contexto.
- Ao executar no computador: marque `- [x]`, commite. Arquivo com todos os itens
  marcados pode ser apagado na limpeza seguinte.

## Regra

Item que exige decisão vira pergunta, não tarefa. Aqui só entra o que já foi
decidido e só falta aplicar.
